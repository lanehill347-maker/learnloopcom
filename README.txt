LearnLoop V3 - No AI Tutor

This is the static LearnLoop learning website. The AI tutor and server function have been removed. Lessons, quizzes, saved progress, and dark mode work in the browser.

Deploy on Netlify:
1. Extract this ZIP on your computer.
2. Open the learnloop-site folder.
3. Upload the contents of that folder to your GitHub repository, replacing the old files.
4. In Netlify, open your site and trigger a new deploy.

No OpenAI API key or server function is required.
